# Carpetas de Intercambio de Prompts y Resultados (ChatGPT <-> Antigravity)

Esta carpeta es la zona común para intercambiar prompts refinados, sugerencias y resultados entre **ChatGPT**, **Antigravity** y el **Usuario** en ReprediSL_V4.

## Archivos de la carpeta

- **`AGENTS.md`:** Contrato de colaboración y reglas del flujo (Usuario -> ChatGPT -> Antigravity).
- **`PROMPTS_CHATGPT.md`:** Registro donde ChatGPT coloca los prompts mejorados y estructurados listos para Antigravity.
- **`RESULTADOS_ANTIGRAVITY.md`:** Registro donde Antigravity deja los informes de ejecución, diffs y resultados para la revisión de ChatGPT y el Usuario.
